# Skill: Create Voiceover with ElevenLabs

Generate an expressive AI voiceover from a script using ElevenLabs, with character-level timing data for video sync. Outputs `voiceover.mp3`, `voiceover_timestamps.json`, and `voiceover_script.txt`.

---

## When to Use This Skill

Use this skill after `plan-script-for-video-ad` to generate the voiceover audio track. The timestamps output can be used for caption generation, lip-sync, or beat-accurate video assembly.

---

## Prerequisites

- ElevenLabs API key: `ELEVENLABS_API_KEY`
- `ffprobe` (part of FFmpeg) for duration measurement
- `jq` for JSON parsing (optional but helpful)
- A Voice ID from your ElevenLabs account

---

## Inputs

| Field | Description |
|---|---|
| `script_text` | The VO copy to synthesize |
| `voice_id` | ElevenLabs Voice ID (from your account or ElevenLabs Voice Library) |
| `target_duration` | Optional: desired audio duration in seconds. Used for atempo calculation. |
| `output_dir` | Directory to save outputs. Default: `./output` |

---

## Model

**Default model: `eleven_v3`**

> `eleven_v3` is the most expressive ElevenLabs model and supports audio tag markup. Do not use `eleven_turbo_v2` or older models for final production — they produce flatter, less natural delivery.

---

## Audio Tags

`eleven_v3` supports inline emotional direction tags. Use these sparingly to shape delivery at key moments.

| Tag | Effect |
|-----|--------|
| `[excited]` | Raises energy and pace slightly |
| `[curious]` | Adds a questioning, exploratory inflection |
| `[reassuring]` | Softens tone, conveys safety and warmth |
| `[understated]` | Pulls back energy, dry/matter-of-fact |
| `[pause]` | Inserts a natural breath/beat |
| `[deliberate]` | Slows and emphasizes the following phrase |
| `[emphasized]` | Stresses the next word or phrase |
| `[sighs]` | Adds a soft exhale before the next line |

### Audio tag rules
- Use **at most 2–3 tags per script** — over-tagging produces stilted delivery
- Place tags immediately before the word or phrase they affect
- Test with and without tags to compare; remove if they don't improve naturalness
- Do not stack multiple tags on the same word

### Example with light tagging
```
You ever catch yourself lying awake [pause] doing math about how much sleep you'll get?
[reassuring] There's actually a better way. It's a nightly sleep supplement with magnesium glycinate —
[deliberate] the most bioavailable form — plus ashwagandha and L-theanine.
By week two, most people wake up without an alarm. [pause] Actually feeling rested.
```

## Default Voice Settings

These settings are tuned for paid-social VO delivery: present and warm, natural variation, minimal over-processing.

| Setting | Value | Notes |
|---------|-------|-------|
| `stability` | `0.34` | Lower = more expressive variation. Raise to 0.5+ for more controlled/clinical delivery. |
| `similarity_boost` | `0.80` | High similarity locks to the voice's core character. |
| `style` | `0.15` | Low = natural. Raise to 0.3–0.4 for more theatrical/heightened delivery. |
| `use_speaker_boost` | `true` | Improves clarity and presence. Keep enabled. |

Adjust settings per use case:
- **Narrator / warm DTC:** stability=0.34, style=0.15 (defaults)
- **Clinical / authoritative:** stability=0.50, style=0.10
- **High-energy / UGC:** stability=0.28, style=0.25

## API Call

Use the `/with-timestamps` endpoint to get character-level timing data alongside the audio.

```bash
curl -sS -X POST \
  "https://api.elevenlabs.io/v1/text-to-speech/${VOICE_ID}/with-timestamps?output_format=mp3_44100_128" \
  -H "xi-api-key: ${ELEVENLABS_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "YOUR SCRIPT TEXT HERE",
    "model_id": "eleven_v3",
    "voice_settings": {
      "stability": 0.34,
      "similarity_boost": 0.80,
      "style": 0.15,
      "use_speaker_boost": true
    }
  }' \
  -o response.json
```

### Decode and save outputs

```bash
# Extract and decode the audio
jq -r '.audio_base64' response.json | base64 --decode > output/voiceover.mp3

# Save the timestamps
jq '{characters: .normalized_alignment.characters, character_start_times_seconds: .normalized_alignment.character_start_times_seconds, character_end_times_seconds: .normalized_alignment.character_end_times_seconds}' response.json > output/voiceover_timestamps.json

# Save the script as rendered
echo "YOUR SCRIPT TEXT HERE" > output/voiceover_script.txt

# Measure the duration
ffprobe -v error -show_entries format=duration -of csv=p=0 output/voiceover.mp3
```

## Known Limitations

### 1. Character timestamps are unreliable with `eleven_v3` + audio tags
The `character_start_times_seconds` field in the response is generated by an alignment model that struggles with the expressive variation of `eleven_v3`, especially around audio tags.

**Do not use these timestamps for caption generation or lip-sync without verification.**

> ✓ **Recommended workflow for accurate timing:** Run the output MP3 through Whisper (word-level timestamps) to get reliable character/word timing.
>
> ```bash
> # Example with whisper-timestamped or whisperx
> whisperx output/voiceover.mp3 --word_timestamps True --output_dir output/
> ```

### 2. Duration is non-deterministic
`eleven_v3` has 5–15% duration variance run-to-run on the same script. The same 30-word script may render as 12.4 seconds one time and 13.8 seconds the next.

**Do not build a fixed-duration video timeline and assume the VO will fit.**

> ✓ **Recommended workflow:**
> 1. Render the video to a fixed duration (e.g., exactly 30.0 seconds)
> 2. Measure the rendered VO duration with `ffprobe`
> 3. Calculate atempo adjustment: `atempo = vo_duration / video_duration`
> 4. Apply atempo in FFmpeg to match VO to video:
>
> ```bash
> # Example: VO is 31.2s, video is 30.0s → atempo = 31.2/30.0 = 1.04
> ffmpeg -i output/voiceover.mp3 -filter:a "atempo=1.04" output/voiceover_synced.mp3
> ```
>
> Note: `atempo` must be between 0.5 and 2.0. For larger adjustments, chain: `atempo=1.5,atempo=1.2`.

## Workflow

```
Step 1 — Receive inputs
  Confirm: script text, voice ID, target duration (if any), output directory.

Step 2 — Shape script with audio tags (optional)
  Review the script for key emotional moments.
  Add at most 2–3 audio tags where they genuinely improve delivery.
  Keep it light — most good scripts don't need more than 1–2 tags.

Step 3 — Call ElevenLabs API
  POST to /v1/text-to-speech/{VOICE_ID}/with-timestamps?output_format=mp3_44100_128
  Use model_id: eleven_v3
  Use default voice settings (or adjusted settings per brief).

Step 4 — Decode and save
  Decode audio_base64 → voiceover.mp3
  Extract timing JSON → voiceover_timestamps.json
  Write script as rendered → voiceover_script.txt

Step 5 — Measure duration
  Run ffprobe on voiceover.mp3.
  Log: actual duration, target duration (if any), delta.

Step 6 — Atempo adjustment (if target duration provided)
  If actual duration differs from target by >0.5 seconds:
    Calculate atempo = actual_duration / target_duration
    Apply FFmpeg atempo filter → voiceover_synced.mp3
    Verify synced file duration matches target.

Step 7 — Report
  Output: file paths, actual duration, atempo applied (if any), notes on delivery.
```

## Full Example: Shell Script

```bash
#!/bin/bash
# Usage: ./generate_vo.sh "Your script text here" your_voice_id 30

SCRIPT_TEXT="$1"
VOICE_ID="$2"
TARGET_DURATION="${3:-}"
OUTPUT_DIR="./output"

mkdir -p "$OUTPUT_DIR"

# Step 1: Call API
curl -sS -X POST \
  "https://api.elevenlabs.io/v1/text-to-speech/${VOICE_ID}/with-timestamps?output_format=mp3_44100_128" \
  -H "xi-api-key: ${ELEVENLABS_API_KEY}" \
  -H "Content-Type: application/json" \
  -d "{
    \"text\": \"${SCRIPT_TEXT}\",
    \"model_id\": \"eleven_v3\",
    \"voice_settings\": {
      \"stability\": 0.34,
      \"similarity_boost\": 0.80,
      \"style\": 0.15,
      \"use_speaker_boost\": true
    }
  }" \
  -o "$OUTPUT_DIR/response.json"

# Step 2: Decode audio
jq -r '.audio_base64' "$OUTPUT_DIR/response.json" | base64 --decode > "$OUTPUT_DIR/voiceover.mp3"

# Step 3: Save timestamps
jq '{characters: .normalized_alignment.characters, character_start_times_seconds: .normalized_alignment.character_start_times_seconds, character_end_times_seconds: .normalized_alignment.character_end_times_seconds}' \
  "$OUTPUT_DIR/response.json" > "$OUTPUT_DIR/voiceover_timestamps.json"

# Step 4: Save script
echo "$SCRIPT_TEXT" > "$OUTPUT_DIR/voiceover_script.txt"

# Step 5: Measure duration
VO_DURATION=$(ffprobe -v error -show_entries format=duration -of csv=p=0 "$OUTPUT_DIR/voiceover.mp3")
echo "Rendered duration: ${VO_DURATION}s"

# Step 6: Atempo if target provided
if [ -n "$TARGET_DURATION" ]; then
  ATEMPO=$(python3 -c "print(round(${VO_DURATION} / ${TARGET_DURATION}, 4))")
  echo "Target: ${TARGET_DURATION}s | atempo: ${ATEMPO}"
  ffmpeg -i "$OUTPUT_DIR/voiceover.mp3" -filter:a "atempo=${ATEMPO}" "$OUTPUT_DIR/voiceover_synced.mp3" -y
fi

echo "Done. Output in $OUTPUT_DIR/"
```
