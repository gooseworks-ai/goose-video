# track-meta-ad-performance

Pull Meta Ads performance data and get a clean, readable report — no spreadsheets, no fussing with field names.

Tell the agent which campaign (or ad set, ad, or the whole account) you want to analyze, what date range, and what you're trying to understand. It fetches the data, formats it, and automatically flags anything that looks off: low CTR, high frequency, budget-capped delivery, and more.

Works best after a campaign has been live for at least a few hours (Meta data has a ~30-60 minute lag).

## Quickstart

```
Read the skill at ./skills/meta-ads/track-meta-ad-performance/SKILL.md and
pull a performance report for my Meta ads.

I want to see: [the whole account / a specific campaign name / a specific ad set]
Date range: [last 7 days / last 30 days / a specific range like 2026-06-01 to today]
```
