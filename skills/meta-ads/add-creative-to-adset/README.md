# add-creative-to-adset

Push a new creative variant into an existing Meta ad set — for A/B testing a different image, video, headline, or copy angle without touching the rest of the campaign.

Tell the agent which ad set to target, provide your creative file and copy, and it creates the creative and the ad (PAUSED by default). Supports both image creatives (via the Meta CLI) and video creatives (via the Graph API for reliable video uploads).

## Quickstart

```
Read the skill at ./skills/meta-ads/add-creative-to-adset/SKILL.md and
add a new creative variant to one of my ad sets.

Ad set to target: [ad set name, or the campaign name to pick from]
Creative: [path to your image or video file]
Headline: [bold text shown under the image]
Body copy: [primary text at the top of the ad]
Link URL: [where the click goes]
```
