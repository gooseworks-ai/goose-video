# explain-meta-ad-setup

Get a skimmable audit of any Meta campaign, ad set, or ad — structure, status, performance, and watch items — in plain English.

Give the agent a campaign name (or ID), and it walks the full tree: campaign → ad sets → ads → creatives. It pulls last-7-day performance, formats everything into a readable report, and automatically flags configuration problems and performance anomalies.

Use this when you want to understand what a campaign is actually doing, or when something looks off and you want a quick sanity check before making changes.

## Quickstart

```
Read the skill at ./skills/meta-ads/explain-meta-ad-setup/SKILL.md and
audit my Meta ad setup.

What to audit: [campaign name / "all my campaigns" / specific ad set or ad name]
```
